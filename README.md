# 🐍 Python File Organizer

### 🚀 Overview
This is a robust automation script written in **Python** that organizes cluttered directories by moving files into specific subfolders based on their file extensions.

It demonstrates practical usage of the `os` and `shutil` libraries for file system manipulation.

### 🛠️ Features
* **Auto-Categorization:** Sorts files into `Images`, `Documents`, `Music`, `Videos`, `Archives`, and `Executables`.
* **Safe Handling:** Checks if folders exist and creates them automatically.
* **Error Proofing:** Includes exception handling to prevent crashes on locked or read-only files.

### 💻 How to Use
1. Clone the repo.
2. Run the script: `python organizer.py`
3. Enter the path of the folder you want to clean (or press ENTER for current directory).
